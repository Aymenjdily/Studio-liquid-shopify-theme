# Studio-liquid-shopify-theme

A Shopify Online Store 2.0 theme (Dawn v16 base) rebuilt to match the
[Studio](https://themes.shopify.com/themes/studio/presets/studio) preset, plus a
library of custom, editor-configurable sections built as vanilla-JS web components.

- `section-library/` — the theme (`shopify theme dev` from this folder)
- `PHASES.md` — build plan and progress for the 12-section library
- `docs/seed/` — demo art catalog (CSV import) and setup guide

## Run locally

```sh
cd section-library
shopify theme dev --store <your-store> --store-password <storefront-password>
```
