# Demo catalog: art products

`art-products.csv` seeds the dev store with 21 art products so the Studio-style
sections show artwork instead of Shopify's sample snowboards.

| Artist (vendor) | Type | Products | Notes |
|---|---|---|---|
| Mara Okafor | Original | 6 abstract paintings | shown framed on cards |
| Juno Lindqvist | Original | 5 watercolours | shown framed on cards |
| Ines Duarte | Print | 4 prints | Size option A4 / A3 / A2 |
| Theo Marchetti | Art Object | 6 ceramics | |

All artists are fictional. Images are Unsplash photos (Unsplash License: free
to use, no attribution required); Shopify downloads them from the
`images.unsplash.com` URLs during import. Products tagged `newest` (6 of them)
feed the homepage "Explore our newest pieces" section.

## Import (about 2 minutes)

1. Admin → **Products** → **Import** → choose `art-products.csv`.
2. Leave "Overwrite products with matching handles" unchecked, then **Import products**.
   Shopify emails you when it finishes. Images can take a minute longer to appear.

### If products show "Sold out"

The first version of the CSV set stock with `Variant Inventory Qty`, which
Shopify ignores when the store has more than one location, so everything
imported at 0. The current CSV doesn't track inventory instead (demo
products never sell out). To fix an earlier import, re-import this CSV with
**"Overwrite products with matching handles"** checked, or in
Products → select all → **Bulk edit** → untick "Track quantity".

## Collections (create once)

Admin → **Products** → **Collections** → **Create collection**, then choose
**Automated** and set a condition:

| Collection | Condition |
|---|---|
| Newest | Product tag is equal to `newest` |
| Prints | Product type is equal to `Print` |
| Originals | Product type is equal to `Original` |
| Art Objects | Product type is equal to `Art Object` |

Artist pages need no setup: `/collections/vendors?q=Mara%20Okafor` works
automatically for every vendor.

## Afterwards

- Point the homepage section at the new collection: theme editor → *Collection
  tabs* → tab block → Collection → **Newest** (or ask Claude to update
  `templates/index.json` to the `newest` handle).
- Optional: archive the sample snowboards (Products → select all → **Archive**)
  so they stop appearing in search and `/collections/all`.
- Menu (Online Store → Navigation → Main menu), matching Studio:
  Prints · Originals · Art Objects · Shop by Artist (four vendor links) · Gift Cards · About.

## Regenerating

The CSV was generated by a one-off script from hand-picked Unsplash search
results; edit the CSV directly to change titles, prices or images.
